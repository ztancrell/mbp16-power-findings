# The 70-Watt Ceiling

Findings page for why a 2019 16" MacBook Pro (MacBookPro16,1: i9-9880H, Radeon Pro 5500M) running
Windows through Boot Camp cuts its CPU and GPU power a few minutes into a game, and what fixes it.

Live page: https://ztancrell.github.io/mbp16-power-findings/

A single static `index.html` (chart data embedded). The research itself lives in a private repository;
this repo publishes only the conclusions and the downsampled measurements behind the charts.
